# 荧光果移植 Mod — 修改说明

## 改动范围

**只改了 1 个文件：`lightbulb.lua`，新增 5 行代码。**

`flower_cave.lua` 使用原版游戏文件，一字未改。

---

## lightbulb.lua 唯一改动

在原版 `OnPutInInventory` 函数之后、`fuel` 组件之前，插入种植部署逻辑：

```lua
-- ★ 唯一新增：右键种植荧光果 → 生成荧光花植株
local function OnDeploy(inst, pt)
    SpawnPrefab("flower_cave").Transform:SetPosition(pt.x, pt.y, pt.z)
    inst.components.stackable:Get():Remove()
end
inst:AddComponent("deployable")
inst.components.deployable.ondeploy = OnDeploy
```

效果：荧光果在物品栏中可右键点击地面，消耗 1 个荧光果，在点击位置生成 1 株荧光花。

---

## 为什么 flower_cave.lua 不需要改

原版 `flower_cave` 的生长系统（`pickable` 组件）独立于光照系统（`LightWatcher`），果实照常重生。

地面与洞穴的行为差异仅在于光照表现：

| 环境 | 光照表现 |
|------|----------|
| 洞穴 | 玩家靠近（带光源）→ 花亮起 → 计时结束熄灭 → 充能 → 等待下次光照触发 |
| 地面白天 | 始终检测到环境光 → 亮起 → 计时结束熄灭 → 充能完成 → 立即再亮起（循环） |
| 地面夜晚 | 无环境光 → 保持熄灭/充能状态，等待天亮或玩家光源 |

地面种植完全可用，只是光照节奏与洞穴不同。如果你想地面和洞穴光照行为也完全一致，需要改 `flower_cave.lua`。
