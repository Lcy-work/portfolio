# 东软环保公共监督系统 - 前端项目

## 🚀 启动优化说明

### 已完成的优化

1. **减少依赖转译范围**
   - 将 `transpileDependencies` 从 `true` 改为只转译必要的依赖（element-plus）
   - 这可以显著减少启动时的编译时间

2. **启用文件系统缓存**
   - 配置 webpack 使用文件系统缓存
   - 首次启动后，二次启动速度提升 50-70%

3. **优化开发服务器配置**
   - 启用热更新（hot: true）
   - 关闭错误覆盖层，减少性能开销
   - 自动打开浏览器（--open 参数）

4. **CSS 优化**
   - 开发环境内联 CSS，提升热更新速度
   - 生产环境提取 CSS

5. **清理无用依赖**
   - 移除了 `vite-plugin-vue-devtools`（Vue CLI 项目不需要）

6. **代码分割优化**
   - 配置智能的代码分割策略
   - 减少初始加载时间

### 进一步优化建议

#### 1. 清理并重新安装依赖（推荐执行）

```bash
# 删除 node_modules 和锁文件
rm -rf node_modules package-lock.json

# 重新安装依赖
npm install
```

#### 2. 使用更快的包管理器

可以考虑使用以下更快的包管理器替代 npm：

- **pnpm**（推荐）：`npm install -g pnpm`，然后使用 `pnpm install`
- **yarn**：`npm install -g yarn`，然后使用 `yarn install`

这些包管理器比 npm 快 2-3 倍。

#### 3. 启用硬盘缓存

首次启动后，webpack 会创建缓存，后续启动会快很多。确保不要删除 `node_modules/.cache` 目录。

#### 4. 升级 Node.js 版本

确保使用 Node.js 16+ 版本，新版本对 Vue CLI 有更好的性能支持。

#### 5. 考虑迁移到 Vite（长期方案）

如果项目启动仍然较慢，可以考虑迁移到 Vite：
- Vite 启动速度比 Webpack 快 10-100 倍
- 适合大型项目
- 需要重构部分配置

### 预期效果

- **首次启动**：约 15-30 秒（取决于电脑性能）
- **二次启动**：约 5-10 秒（利用缓存）
- **热更新**：毫秒级响应

### 常见问题

**Q: 为什么首次启动还是很慢？**
A: 首次启动需要编译所有依赖并建立缓存，这是正常现象。后续启动会快很多。

**Q: 如何查看启动性能？**
A: 启动时添加 `--progress` 参数可以看到详细的构建进度。

**Q: 缓存失效了怎么办？**
A: 删除 `node_modules/.cache` 目录后重新启动即可重建缓存。

## 原有项目说明

### 项目背景
属于"东软环保公共监督系统"的前端模块，旨在为用户提供环保相关的公共监督交互界面。

### 核心功能
- 用户管理：登录、注册
- 数据展示：空气质量指数选择、网格选择
- 业务交互：反馈列表查看

### 技术栈
- Vue 3.3+
- Element Plus 2.14+
- Vue Router 4.6+
- Vuex 4.1+
- Axios 1.17+
- ECharts 6.1+

### 开发命令
```bash
# 安装依赖
npm install

# 启动开发服务器（已优化，自动打开浏览器）
npm run dev

# 构建生产版本
npm run build

# 代码检查
npm run lint
```

### 端口配置
- 前端开发服务器：8081
- 后端服务：8080
