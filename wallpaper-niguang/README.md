# Wallpaper Engine 场景壁纸「逆光」

将「樱花庄的宠物女孩」动态壁纸逆向改造成「逆光」主题场景壁纸：替换背景音乐、歌词逐句时间轴显示、四图循环轮换。

## 技术栈

- Wallpaper Engine SceneScript
- scene.pkg（PKGV0021）/ .tex（TEXV0005）二进制格式逆向

## 内容

| 文件 | 说明 |
|------|------|
| `逆光壁纸_2026-08-13_v2.zip` | **可直接安装的壁纸交付包**（43MB） |
| `preview.gif` | 预览动图 |
| `pkg_tool.ps1` | scene.pkg 解包/打包工具 |
| `使用说明.txt` | 安装与使用说明 |

## 安装

1. 解压 zip
2. 用 Wallpaper Engine「从文件打开」加载，或覆盖 workshop 目录（见使用说明）

## 体现能力

- 二进制格式逆向解析（无文档的未知格式独立拆解复现）
- 图形/渲染脚本（歌词时间轴同步、四图轮换）
