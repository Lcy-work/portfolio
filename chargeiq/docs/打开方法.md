# ChargeIQ 新能源充电桩大数据平台 — 打开方法

## 环境要求

- VirtualBox 中已安装 Ubuntu 24.04 虚拟机
- 虚拟机中已配置 Hadoop 2.6 + MySQL + Python 3

---

## 启动步骤（三步）

### 第一步：打开虚拟机

1. 打开 VirtualBox
2. 启动 Ubuntu 虚拟机
3. 用 MobaXterm SSH 连接（或直接在虚拟机终端操作）

---

### 第二步：启动 Hadoop

```bash
su - hadoop
# 输入 hadoop 用户密码
bash
start-all.sh
```

验证（看到 5 个进程即为成功）：
```bash
jps
# NameNode, DataNode, SecondaryNameNode, ResourceManager, NodeManager
```

---

### 第三步：启动 Web 应用

新开一个终端标签：

```bash
cd "/home/lcy/大三下实训第二个项目/项目代码/flask-webapp"
python3 app.py
```

看到 `Running on http://0.0.0.0:5000` 即启动成功。

---

## 打开页面

浏览器访问：

```
http://localhost:5000
```

| 功能 | 操作 |
|------|------|
| 首页（10个功能卡片） | 直接访问 |
| 数据分析图表 | 点击对应卡片进入 Dashboard |
| 实时监控大屏 | 点击"📡 进入实时监控大屏" |
| 机器学习预测 | 点击"🤖 机器学习预测"区域的卡片 |

---

## 常见问题

| 问题 | 解决 |
|------|------|
| 页面没数据 | 重跑 MapReduce |
| Hadoop 启动失败 | `stop-all.sh` → 删除 `/tmp/hadoop*` → 重新 `start-all.sh` |
| Flask 端口被占用 | `pkill -f python3` 然后重新启动 |
| 连不上 localhost | 检查 VirtualBox 端口转发（5000 → 5000） |
